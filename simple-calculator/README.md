
# Simple Calculator

A terminal-based calculator written in C.

## Compilation

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

## Run

./calculator

## Supported Operations

- Addition
- Subtraction
- Multiplication
- Division

## Numeric Behavior

The menu accepts integer choices from 0 to 4.
Arithmetic operations are not implemented yet.

## Known Limitations

Non-numeric input is not fully supported.
