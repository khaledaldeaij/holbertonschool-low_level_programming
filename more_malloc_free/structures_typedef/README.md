
# C - Structures, typedef

This project is part of the Holberton School Low-Level Programming curriculum.

## Description

This project introduces structures and typedef in the C programming language.

## Learning Objectives

- Understand structures in C.
- Learn how to declare and initialize structures.
- Access structure members.
- Use pointers to structures.
- Understand and use typedef.
- Document structures using Betty style.

## Files

- `dog.h`: Defines the `struct dog` structure with name, age, and owner members.

## Compilation

All C files are compiled using:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89
