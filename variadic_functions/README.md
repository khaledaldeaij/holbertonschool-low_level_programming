# C - Variadic Functions

This project covers variadic functions in C and how to handle
a variable number of arguments using the stdarg.h library.

## Learning Objectives

- Understand variadic functions.
- Use va_list, va_start, va_arg, and va_end.
- Understand the const type qualifier.
